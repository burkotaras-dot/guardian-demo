# Середа, 19.08.2026 — Interaction Pattern Library v1

Задача дня: зібрати задачну бібліотеку поверх учорашнього Wizard Pattern — не новий набір правил,
а 14 готових рецептів для типових задач (Create, Edit, Delete, Configure, Test Connection, Mapping,
Save, Cancel, Confirmation, Long-running task, Success, Warning, Error, Empty State), кожен у
форматі Behaviour / Layout / Actions / States / Edge cases.

## Що зроблено

Новий файл `GUARDIAN-PATTERN-LIBRARY.md`. Для 11 із 14 патернів правило вже існувало в
`GUARDIAN-INTERACTION-STANDARDS.md` (написаному в понеділок-вівторок) — робота полягала в тому,
щоб перепакувати його під задачу й дати одне посилання на реальний екран, а не переписувати
значення вдруге.

3 патерни виявились не описані раніше й пройшли той самий аудит коду, що вчорашній wizard:

- **Configure** — параметри операції над уже створеною сутністю (сканування AWS, обсяг, розклад).
  Секції вибору групуються за змістом, підопції розкриваються самим CSS без JS, поруч завжди
  контекстна підказка і оцінка часу перед запуском.
- **Mapping** — зіставлення полів (CSV/ServiceNow → Guardian). Три кроки: вибрати поля →
  налаштувати мапінг → перевірити й активувати. Кожен рядок мапінгу має власний статус
  (не протестовано / пройшло / попередження / конфлікт / помилка), і будь-яка зміна після тесту
  цей статус скидає — застаріле «пройшло» ніколи не переноситься на змінений мапінг.
- **Create (одностадійний)** — з'ясувалось, що Create і Edit у простих формах (наприклад,
  credential) — буквально один і той самий код, який лише міняє заголовок і напис на кнопці
  залежно від того, редагується існуючий обʼєкт чи створюється новий.

Один побічний знахідок записано, але навмисно не виправлено цього тижня: статус рядка в Mapping
намальований вручну, а не через канонічний бадж-компонент — це дрібне порушення правила
«статус = один компонент», кандидат для наступної консолідації баджів.

## Де подивитись

Кореневий файл `GUARDIAN-PATTERN-LIBRARY.md` — новий, поруч із `GUARDIAN-DESIGN-SYSTEM.md` і
`GUARDIAN-INTERACTION-STANDARDS.md`. У самому Standards оновлено таблицю «Межа з Design System» —
тепер вона на три документи, а не на два.
