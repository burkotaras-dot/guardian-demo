## Зроблено

### 1. Наскрізний Essentials-флоу (один шлях)
```
Перший вхід
  → вибір способу підключення (CM / agentless)
  → додати вузол (agentless / ServiceNow / CSV)
  → креденшели (нові / з Vault)
  → розклад скану
  → перший скан
  → результат скану
  → встановити baseline
  → виявлений drift
  → розслідування змін
  → реконсиляція або export
```
Усі 68 екранів клієнта лягають на цей ланцюг — розривів у happy path немає.

### 2. Пріоритетні journeys (порядок показу клієнту)
1. Agentless add node → 2. Підготовка до скану → 3. Перший скан → 4. Результат →
5. Baseline → 6. Detected drift → 7. Import ServiceNow → 8. Import CSV → 9. Reports.

| Потік | Чого бракує |
